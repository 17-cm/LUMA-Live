# LUMA Live (v3.3.2)

原生极简轻奢虚拟直播平台，支持全网状态同步、角色自主开播下播工具、全仿真沉浸式直播间与小手机原生集成。

---

## 🚀 最新版本改动日志 (v3.3.2)

### 1. 👥 直播内外在看人数精确同步
- **数值与计算统一**：直播广场封面右下角与直播间内右下角的在看人数实现同源读取与动态同步，解决此前内外数值不一致的问题。

### 2. 👑 主播信息胶囊区对齐个人主页样式
- **高奢彩框头像**：采用与个人主页一致的炫彩流动渐变高光头像外框。
- **VIP 等级徽标**：头像右下角镶嵌立体专属 VIP 等级徽标（如 `VIP 9`）。
- **主播 ID 与金 V 章**：主播名称右侧紧跟官方认证金 V 标识。
- **粉丝数与称号排布**：下方左侧展示粉丝数（初始值设为 `0`，适配后续涨粉体系），粉丝数右侧紧跟专属头衔称号胶囊（如 `【新人主播】`）。

### 3. 🎁 送礼公屏大横幅头像与身份同步
- **玩家真实头像**：玩家送出礼物时，公屏顶部流光大横幅自动抓取玩家当前真实头像、个人称号与 VIP 等级。
- **角色/NPC 随机头像**：野生主播与 NPC 互动送礼时随机匹配头像库与专属头衔，呈现更真实的直播互动氛围。

### 4. 💬 弹幕体系与个人称号/ID 同步
- **全新弹幕气泡**：弹幕条内嵌发送者圆形头像、`【称号】` 高光标签、`ID:` 与发言内容。
- **玩家身份同源**：玩家发送弹幕与送礼弹幕自动同步当前个人称号（如 `【新人主播】`）加名称 ID。
