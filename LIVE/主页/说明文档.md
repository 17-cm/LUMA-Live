## 代码位置速查

### 主播个人主页（streamer_profile.js）关键函数

| 功能 | 函数名 | 说明 |
|------|--------|------|
| 打开主播主页 | `openStreamerProfilePage(id)` | 别名 `openStreamerSpace` |
| 关闭主播主页 | `closeStreamerProfilePage()` | |
| 档案生成（兜底） | `getOrGenerateStreamerProfile()` | 同步生成，含随机兜底值 |
| **AI 初始值生成** | `generateProfileAISettings()` | **读取角色人设 + 世界书，AI 生成**个性签名/认证/IP属地/粉丝团前缀/标签 |
| 编辑档案（铅笔） | `spOpenProfileEdit()` / `spSaveProfileEdit()` | 五项可编辑：个人认证、个性签名、IP属地、粉丝团前缀、四个 #标签 |
| 主页渲染 | `renderStreamerProfileToUI()` | |
| 关注 | `spToggleFollow()` | |
| Tab 切换 | `switchSpTab()` | 仅剩：直播场次 / 相册 / 留言墙（动态 Tab 已隐藏，等社区真实功能） |
| 留言墙 | `submitGuestbookComment()` | |

### 主播主页数据存储（宿主 db 表）

| 表名 | 用途 |
|------|------|
| `streamer_covers` | 用户上传的主播封面（base64） |
| `streamer_profile_edits` | 铅笔编辑的档案存档（**优先于** AI/随机值） |
| `streamer_profile_ai` | AI 生成档案缓存（人设+世界书，首次打开生成一次） |
| `guestbook` | 留言墙数据 |

## 加载顺序

`index.html` 尾部静态脚本 + `LIVE/splash.js` 的 `JS_LOAD_ORDER` 均已登记：

```
... → LIVE/直播/live.js → LIVE/主页/streamer_profile.js → LIVE/设定/main.js → ...
```

`streamer_profile.js` 必须在 `live.js` **之后**加载（依赖其全局状态与直播间函数）。
